# Sound asset sources

The app includes three MP3 assets generated from openly licensed source audio.

| App file | Source | License and attribution |
|---|---|---|
| `purr.mp3` | [Purring cat - Bertie](https://commons.wikimedia.org/wiki/File:Purring_cat_bertie.ogg) | Public domain. Original recording by jim_mowatt; source audio was converted from OGG to MP3. |
| `meow.mp3` | [Meow.ogg](https://commons.wikimedia.org/wiki/File:Meow.ogg) | Creative Commons Attribution-ShareAlike 3.0 Unported. Original recording by Dan Crosby (Dcrosby); converted from OGG to MP3. |
| `happy.mp3` | Derived from `purr.mp3` | Public-domain source, adjusted for speed and volume to create a short positive feedback sound. |

The `meow.mp3` asset requires attribution and ShareAlike compliance under its source license. Keep this file with any distributed build or store submission materials.
